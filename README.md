# NN - Import Finder

Unityで直前にImportしたフォルダを見つけやすくするEditor拡張です。

## VCC / VPM

Package ID: `com.nekoneko.nn-import-finder`

VPM Repository URL:

`https://raw.githubusercontent.com/kureh4/NN-Import-Finder/main/Website/index.json`

VCCの **Settings > Packages > Add Repository** から上記URLを追加すると、
Manage Projectから **NN - Import Finder** を導入できます。

## VCC追加WebUI

`https://kureh4.github.io/NN-Import-Finder/add-vcc.html`

BOOTH等には上記URLを掲載できます。

## 対応環境

Unity 2022.3.22f1
