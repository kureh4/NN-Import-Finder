# NN - Import Finder

Unityで直前にImportしたフォルダを見つけやすくするEditor拡張です。

## VCC / VPM

### Repository Listing URL

```text
https://raw.githubusercontent.com/kureh4/NN-Import-Finder/main/index.json
```

VCCの **Settings > Packages > Add Repository** に上記URLを貼り付けて追加してください。

### VCCプロトコル

```text
vcc://vpm/addRepo?url=https://raw.githubusercontent.com/kureh4/NN-Import-Finder/main/index.json
```

対応Unity: **2022.3.22f1**

Package ID: `com.nekoneko.nn-import-finder`
